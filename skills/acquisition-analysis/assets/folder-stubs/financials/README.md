# Financials

Organized financial docs. Suggested file naming:

```
pnl-YYYY-annual.xlsx
pnl-YYYY-monthly.xlsx
tax-return-YYYY.pdf
balance-sheet-YYYY-MM.xlsx
ar-aging-YYYY-MM.xlsx
ap-aging-YYYY-MM.xlsx
bank-stmt-YYYY-MM.pdf
customer-list-YYYY-MM.xlsx
qoe-report.pdf
addback-schedule.xlsx
```

Keep seller-provided files as-is; put your normalized working files in a `working/` subfolder if you rebuild their numbers.
